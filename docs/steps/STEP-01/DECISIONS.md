# STEP 01 - DECISIONS

1. Route collision: route groups share one URL space, so `app/(admin)/<page>` and `app/(dashboard)/<page>` would collide (settings, support, payments, disputes) and both homes would collide with the public home. Decision: admin pages live under `/admin`, the dashboard home is `/dashboard`. All SCOPE files and OWNERSHIP_MAP were updated. (Source: Next.js routing; precedence level 3 does not cover it.)
2. Fragment naming: every fragment is prefixed `sNN-` so that ownership inside shared directories is decided by file name (OWNERSHIP_MAP section 6).
3. `instrumentation.ts` moved from STEP 04 to STEP 01 (fail-fast environment validation and bootstrap run there). STEP 04 adds Sentry through `config/boot/s04-*`.
4. Contract `idempotency` added (STEP 04 implements) because `withApi` needs it for payment and API idempotency.
5. Fonts: the system font stack is used so builds need no network access.
6. `console` is used in exactly one file, `lib/logger/sink.ts`, because the Edge runtime has no `process.stdout`. Guard and ESLint exempt only that file.
7. Rule 17 (approval chain) is implemented by STEP 02 through `lib/auth/approval-rules.ts`; STEP 01 only defines the contract.
8. Preview pages answer with the not-found body outside development, but because `loading.tsx` streams the shell first the HTTP status can be 200. The STEP 04 middleware returns a real 404 for `/dev/*` in production (ADR 0003).
9. `lib/logger/index.ts` exports only browser-safe modules. Server code imports request context helpers from `@/lib/logger/correlation` (it uses `node:async_hooks`).
10. Dead-link guard tolerates links to routes listed in `config/planned-routes.json` (pages of later STEPs). The Release Gate runs it with `--strict`.
11. Touch targets: checkbox and switch hit areas are 44 px; the visible control is smaller.
12. `package.json` pre-installs the planned stack, including `@react-email/components` 1.x and `@react-email/render` 2.x (the 0.0.x line is deprecated upstream).
13. CI review (after the first push): fixed eight problems found by GitHub Actions. (a) Semgrep: every action is pinned to a full commit SHA, Dependabot has a 7-day cooldown, the deploy workflow has no `workflow_dispatch` inputs and no `${{ }}` inside `run` (split into `deploy-netlify.yml`), nginx no longer forwards `$host` (an explicit `APP_DOMAIN` template is used and other Host values are refused). (b) `aquasecurity/trivy-action` tag name corrected (`v0.36.0`). (c) Checkov CKV_GHA_7 satisfied by removing the inputs. (d) `npm audit` reported 1 critical and 13 high findings: the critical one (Next.js 14) has its fix only in Next.js 16, so the project moved to Next.js 16.4.1, React 19, ESLint 9 (flat config), Sentry 11, nodemailer 10, sharp 0.35, tiptap 3, @react-pdf/renderer 4, @googleapis/drive 26; `npm audit --omit=dev` now reports 0. (e) Tailwind CSS 3, PostCSS and Autoprefixer moved to devDependencies; the remaining dev-only findings (chokidar, braces, fast-glob in Tailwind 3 and the ESLint config chain) have no fix and are build-time tools, so the CI gate excludes dev dependencies. (f) The Lighthouse job runs only when the public home page exists (STEP 06). (g) Node 22 LTS is the runtime (`.nvmrc`, Dockerfile, Netlify); Node 20 is end-of-life. (h) Dependabot ignores semver-major updates of packages that need a planned migration (zod 4, @hookform/resolvers 5, tailwind-merge 3, Tailwind 4, @types/node, React, Docker node image).
14. Next.js 16: `middleware.ts` is named `proxy.ts` (STEP 04), request APIs such as `headers()` are asynchronous, `next lint` and the `eslint` key of `next.config.js` are gone (ESLint runs directly through `eslint.config.mjs`), `instrumentation.ts` needs no flag, `experimental.serverComponentsExternalPackages` became `serverExternalPackages`, Turbopack is the default bundler.
15. React 19 removed the global `JSX` namespace; `types/global.d.ts` restores `JSX.Element` so component return types stay as written in this repository.
16. Theme provider uses `useSyncExternalStore` (React 19 lint rule forbids setting state in an effect).
