# STEP 04 decisions

- D1 (04.1) CSP: scripts use a per-request nonce with 'strict-dynamic' and no 'unsafe-inline'. `style-src-attr 'unsafe-inline'` stays because React inline style props and the animation library need it; `<style>` elements carry the nonce. Trusted Types are sent as a report-only header first, because the Turnstile loader assigns a script URL as text; enforcement follows once the report shows no violation.
- D2 (04.1) The SSRF guard checks the address at socket open time (custom lookup) as well as before the request, so DNS rebinding cannot reach private addresses. Redirects are never followed.
- D3 (04.3) `app/layout.tsx` (STEP 01) mounts `CsrfInit`, a client component that adds the `x-csrf-token` header to every same-origin state-changing fetch call. The token is a signed cookie (`kd_csrf`, readable by script by design of the double-submit pattern); it is replaced at sign-in and sign-out. The Origin (or Referer) check is applied in addition. Server-to-server routes (`/api/webhooks/`, `/api/cron/`, `/api/public/`, `/api/health`) are exempt from CSRF and from the user-agent check because they authenticate by secret or signature.
- D4 (04.3) The proxy was run against a production build (dummy environment): headers present, `/dev/*` answers 404, empty and scanner user agents answer 403, a POST without or with a foreign origin answers 403, a POST with a valid token reaches the route, and every script tag carries the nonce.
