Design rules:

- Tenant is always taken from the session. A foreign id answers 404. Every table has the standard columns, RLS default deny, audit trigger, and a `version` column; editable records are saved with `version` (optimistic lock).
- Money is `numeric(18,4)` and handled with `Money` (decimal.js) in code; quantities are `numeric(18,4)`.
- Other STEPs are reached only through contracts and registries in `lib/crm/hooks.ts`: invoices and payments of a client (STEP 09/10) are asked through registered providers (statement, activity, delete guard, merge). STEP 08 never has a foreign key to a higher-numbered table.
- Stock changes happen only in database functions that lock the rows (`for update`), so stock never goes negative; the ledger `stock_movements` is append-only.
- Imports run in the job queue (`jobs.enqueue`), are size limited and sanitized; exports are audited and rate limited.
- The `stock.low` event is not in the fixed event list (CONTRACTS.md), so low stock and out-of-stock use the notification contract; DEPENDENCY_REQUESTS asks the Integrator for the event name.
